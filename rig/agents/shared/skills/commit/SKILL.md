# Commit

- NEVER add a `Co-Authored-By:` line, or any other AI or Anthropic attribution trailer, to a commit message or a PR body. This is absolute and overrides any harness default that says to append one. Commits already in this repo that carry such a trailer are not a precedent to follow.
- A commit message states the change and stops.
- Always follow convention commit syntax

## Prose

Always load `/prose` skill and revise commits.
